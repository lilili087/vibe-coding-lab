## 项目结构

每个作品使用独立目录：

```text
projects/
  YYYY-MM-DD-project-name/
    README.md
    src/
    assets/
```

项目 README 至少记录：

- 项目目标与使用场景
- 核心功能与演示方式
- 技术栈与关键决策
- 本地运行方法
- 验证结果与已知问题
- 复盘结论与下一步优化

## 状态说明

- `Idea`：想法阶段
- `Building`：开发中
- `MVP`：最小可用版本已完成
- `Iterating`：持续优化中
- `Archived`：停止维护但保留记录

## 使用原则

- 先定义最小可用版本，再开始实现。
- 优先选择简单、稳定、容易维护的方案。
- 每个关键阶段留下清晰的提交记录。
- 不提交密码、令牌、私钥、个人隐私或内部资料。
- 每个项目完成后记录验证结果、问题和后续计划。
