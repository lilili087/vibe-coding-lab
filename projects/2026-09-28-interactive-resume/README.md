# 交互式个人简历网站

## 项目简介

一个面向招聘方与作品集访客的动态个人简历。网站以红黑票券封面为入口，通过人物开场动画、悬停状态和可展开的内容卡片，集中展示 AI 产品、项目、校园与荣誉经历。

## 目标用户

- 招聘经理与面试官
- AI 产品及互联网产品岗位团队
- 希望快速了解个人经历与能力成长的作品集访客

## 核心功能

- 静音人物开场动画，支持跳过和重新播放
- 四张封面卡片对应实习、项目、校园和荣誉详情
- 实习经历采用纵向时间线与可展开“信封”卡片
- 职责和成果分点呈现，关键成果数据突出显示
- 校园经历按学生工作、社会实践和志愿活动组织
- 支持减少动态效果、键盘操作和视频失败回退
- 桌面及移动端自适应
- 网页内复制公开分享链接

## 技术栈

- 前端：HTML、CSS、原生 JavaScript
- 媒体：WebP、MP4
- 后端：无
- 构建工具：无
- 部署方式：静态托管

## 目录结构

```text
site/
  index.html
  style.css
  app.js
  content.js
  experience.js
  campus.js
  assets/
```

## 本地运行

进入项目目录后启动任意静态服务器：

```powershell
python -m http.server 8765 --directory site
```

然后访问 `http://127.0.0.1:8765/`。请勿直接双击 HTML 文件，浏览器对本地媒体和剪贴板的限制可能导致部分功能不可用。
