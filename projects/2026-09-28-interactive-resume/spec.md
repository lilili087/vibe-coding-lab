# 交互式个人简历网站规格

## 背景

将现有的动态个人简历网站整理为可持续维护的公开 GitHub 项目，便于后续优化、复盘和作品展示。

## 目标

- 完整保存当前可运行的网站源码与必要媒体资源。
- 保留封面动画、卡片状态、详情弹窗、实习时间线、移动端适配及无障碍交互。
- 提供清晰的本地运行、验证和在线演示说明。
- 将项目纳入 `vibe-coding-lab` 的作品目录。

## 非目标

- 不迁移 Sites 的内部部署身份或凭据。
- 不加入原始简历、联系方式、微信、籍贯、政治面貌等敏感信息。
- 不在本次工作中改变网站内容、视觉或在线部署平台。
- 不额外配置 GitHub Pages；在线演示沿用现有公开网站。

## 用户场景

1. 访问者打开网站，观看或跳过人物开场动画。
2. 访问者点击四张主题卡片，查看实习、项目、校园与奖项详情。
3. 访问者展开实习“信封”，阅读分点职责、量化成果和收获成长。
4. 访问者在手机或桌面浏览器中阅读并复制分享链接。
5. 维护者克隆仓库后，通过本地静态服务器预览和修改网站。

## 功能要求

- 静音播放开场视频；播放失败时回退到静态封面。
- 支持跳过、重新播放和减少动态效果。
- 四张封面卡片可点击打开相应详情。
- 实习经历采用纵向时间线和可展开信封布局。
- 项目、校园经历和荣誉内容可在弹窗内阅读。
- 分享功能在页面内展示并复制公开网址。
- 适配桌面和移动端，不出现横向溢出。

## 非功能要求

- 使用原生 HTML、CSS 和 JavaScript，无运行时依赖和构建步骤。
- 主要交互支持键盘操作。
- 尊重系统的减少动态效果设置。
- 媒体文件采用浏览器可直接加载的格式。
- 公开仓库不得包含凭据和非必要敏感信息。

## 约束

- 网站中的经历与数据只能来自已确认的个人资料。
- 论文保持“在投”状态，不写成已发表或录用。
- 志愿服务累计数字存在历史口径差异，未确认前不新增展示。

## 验收标准

- [x] 静态服务器可成功打开首页，页面无 JavaScript 运行错误。
- [x] 四个详情入口、实习信封展开收起、分享和减少动态效果可用。
- [x] 桌面及 390px 宽移动端无横向溢出。
- [x] 代码和资源中不包含电话、邮箱、微信、密钥或令牌。
- [x] 根项目索引包含该项目及在线演示链接。
